# ContactManager

Exercice du projet 5 OpenClassrooms c'est un petit outil en ligne de commande
pour gérer des contacts (en PHP objet avec une base MySQL).

## Installation

1. Cloner le projet
2. Créer une base par exemple `contact_manager` et importer `data.sql` dedans
3. Copier `config.example.php`, le renommer en `config.php` et mettre ses identifiants MySQL et le nom de la base

## Lancer le programme


taper `php main.php` dans le terminal.
Ensuite taper `help` pour voir les commandes.
